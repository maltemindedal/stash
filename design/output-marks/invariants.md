# Output: invariants and how each is checked

"Checked by" names the mechanism. A type or signature makes the mistake a compile error. The model is the exhaustive checker in `model_test.go`, which compares the core with a byte-tagged reference after every operation of every sequence up to a depth. A property test runs over the same sequences. "Proven here" means `design/output-marks/proto` runs that check today and rejects the past rule. "Designed" means the check belongs to the full package and has not been built yet.

|---|---|---|---|---|
| 1 | The read gate (`MayReadNext`) counts exactly the unwritten bytes up to the end of the latest Reply, so pushes ahead of the Reply count and pushes after it do not. | Model. The reference counts tagged bytes up to the last Reply byte. | ca505a9 (its parent waited on the whole backlog: `Reply(1), Push(5), Flush?`). 5a28666 (ca505a9's own `replyWaiting` is 5a28666's parent: `Push(5), Reply(1), Flush?`). | Proven here |

| 6 | A Polled writer is judged stalled only by an attempt that takes nothing after the timeout. | 7 | A closed stream has nothing waiting: `Written == Offered == Queued`, `Held == 0`, and no buffer. | Core. `close` sets the marks and drops the buffers. | 8 | Bytes reach the socket in the order they were produced, and a push queued before a request is ahead of that request's Reply. | Model with byte content. | 9 | The core does no I/O, takes no lock, reads no clock and starts no goroutine. Every effect runs in `Output.apply` after the lock is released. | Structure. `stream` returns `Effects`. | 10 | Nothing that holds a registry's or the Master's lock can wait on a socket. | Type. `ClientState.Output()` returns `Port`, which has no `Flush`, `Finish` or `Reply`. | The AGENTS.md rule "Neither waits on the socket". No past commit broke it, so this is preventive. | Designed |
| 11 | Every Reply is encoded before the lock is taken. | Structure. `Reply` always encodes into the owner's scratch buffer, so `isLargeReply` goes. | 04772a0 (the doc described the bulk-string-only rule wrongly). 75f9704's split into `ahead` and `queued`, which 878dcef then had to repair. | Designed (needs a benchmark) |
